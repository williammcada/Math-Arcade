# Math Arcade v0.10.0-rc.1 — universal answer pad (implementation checkpoint)

**Status:** Implementation checkpoint on `implement/v0.10.0-answer-pad`, from `main` `77a39a2` (0.9.1). Not a verified release until CI and the owner's iPad check pass on the merged commit.
**Spec:** [v0.10.0-answer-pad](../change-specs/v0.10.0-answer-pad.md) · **Handbook:** `9d9c80f` (v0.1.12): U-18, U-14 as amended, U-04, U-10.

## What changed

- **Engine files:** `vendor/math/` now holds Engine `9452ab4`: the practice bundle, its provenance and `answer-pad.js`, recorded in `vendor/manifest.json`. The upstream sync now keeps `src/answer-pad.js`.
- **Browser module:** `scripts/build.mjs` wraps the Engine pad, unedited, as the browser module `/answer-pad.js`. The Node host (`server/index.mjs`) and the Worker assets (`scripts/build-assets.mjs`) serve it.
- **One answer helper:** `public/answer-entry.js` serves all three answer screens:
  - the main gate (`public/app.js`);
  - the adventure gate for Chrono Circuit and Olivia (`public/campaign-runtime.js`);
  - the Kingsgate question round (`public/kingsgate-game.js`).

  Keypad questions use the Engine pad. Choice questions keep their buttons, and text questions keep a text box.
- **Pad styling:**
  - Host CSS keeps the pad's own look where game button styles would override it (`.keypad button`, Kingsgate's dark `.flight-root button`, `.classroom-gate button`). Keys and their order are unchanged.
  - The Kingsgate question round now shows the question beside the pad (panel up to 820 px wide, one column under 620 px), so the pad and **Check answer** fit without scrolling.
- **Tests:**
  - Browser suites enter answers through the pad with a physical keyboard (`test/answer-input.cjs`), since keypad answer boxes are now read-only.
  - The Olivia suite now checks the pad's two tabs and that 123 opens first, instead of the old 4-column grid.
  - New tap-only suite: `test/answer-pad-browser.cjs`.
- **Version:** 0.10.0-rc.1.

### New tap-only test

Four students, each on a touch page (two at 1024 × 768 and two at 768 × 1024), each answered two questions of one form using only pad taps:

- **Remainder:** `29 R 2`, `2 R 2`. This is the classroom failure.
- **Fraction:** `1/8`, `1/4`.
- **Negative decimal / integer:** `−7`, `−6`.
- **Inequality** (Algebra tab): `x>8`, `x≥−2`.

On every question:
- both tabs showed exactly the U-18 keys in order, and 123 opened first;
- the answer box was read-only with `inputmode="none"`;
- the server accepted the answer.

The first question of each pair was submitted with Enter from a physical keyboard while the Algebra tab was showing. The next question opened on 123. There were no page errors.
