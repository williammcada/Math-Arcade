## Implemented

Separate `math-arcade` Cloudflare Worker and SQLite-backed `ArcadeWorkspace` Durable Object. Storage-independent classroom model and shared API dispatch preserve seven game policies, passwords/approval, assignments, authoritative rounds, leases, saves, export and deletion. Same-origin Static Assets preserve cookie authentication; protected adventures require authorization before every asset fetch. Chunked transactions preserve large Unicode saves and roll back failed changes. Worker reinitialization pauses rounds without restoring lives or time. Version/credit are present in the main and generated campaign HTML.

This shares MathQuest's backend infrastructure family. It uses a single Worker origin instead of MathQuest's GitHub Pages/Netlify relay route. MathQuest's Worker, namespace and live rooms were not changed.
