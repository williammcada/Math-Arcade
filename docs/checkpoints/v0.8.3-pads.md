# Math Arcade v0.8.3 — directional pads (U-17) and full-screen Coastal Escape (implementation checkpoint)

**Status:** Implementation checkpoint. Not tested on an iPad, not merged, not deployed. Spec: [v0.8.0](../change-specs/v0.8.0.md) C1; handbook U-17 (approved 2026-10-15, handbook `6e1f5a4`) and U-10.

## What changed

- New Arcade module `public/pad.js`: two layouts, built once —
  - **cross** (Mega Man Math): up, down, and wide left/right meeting in the middle;
  - **eight**: the same pad plus corner arrows, a full 3 × 3 of directions with no empty cells.
  The whole pad is one held-input zone, so sliding between arrows changes direction; contact ownership and release come from the shared MathQuest `held-input.js` (U-10). Action buttons: first two are round (Mega Man A/B style), the rest small.
- Pad docked bottom-left, actions bottom-right, status and utility buttons between, so the game keeps the rest of the screen.

| Game | Before | Now |
|---|---|---|
| Nightfall 1 | 4 labeled buttons | Mega Man cross (up = forward, down = reverse, left/right = turn); Run, Fire round; Search/Use, Change weapon small |
| False Haven | same | same as Nightfall 1 |
| Journey | 4 arrow buttons in a horizontal row | 8-direction pad; Attack, Jump round; Magic small |
| Coastal Escape | 3 × 3 slide pad in a side rail; 640-px battlefield | 8-direction pad; battlefield fills the screen |
| Ironbreak | 4 labeled buttons in a row | 8-direction pad (diagonals aim/move diagonally); Jump, Prone round |
| Vault 7, Blackline, Blackout, Kingsgate, Chrono, Olivia, Math Civ | — | unchanged |

Keyboard controls unchanged. DEV mode uses the same hosts, so it shows the new pads.
