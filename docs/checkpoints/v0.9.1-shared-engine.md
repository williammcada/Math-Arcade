## Changes

- Synced MathQuest `5a5d7c6` (0.14.0) into `vendor/` with the normal `scripts/sync-upstream.mjs`; other sources unchanged (Math Engine `9b2abef`, Chrono, Olivia, Math Civ).
- Arcade hosts (Nightfall 1, False Haven/Journey/Blackline/Blackout via `extra-games.js`, Coastal `flight.js`, Ironbreak) now use `/coastal/engine/controls.js`, which renders and binds MathQuest's `engine/pad.js`. The page loads `/coastal/engine/audio-unlock.js`.

- `style.css` keeps only the Arcade's pad dock layout; pad looks come from MathQuest.
- Arcade-owned and unchanged: campaign iframe sound wake (Chrono, Olivia, Math Civ), DEV playtest, teacher desk.
- The synced MathQuest files include `teacher-gate.js` / `teacher-guard.js`; the Arcade does not use them (Arcade's own teacher password protects its desk and DEV mode).
