## What changed

- **A1 Enlargeable QR:** tap the QR or **Enlarge QR**. Sizes 100% / 200% / 300% (default) / Fit screen; the choice is remembered on that computer. The large view also shows the class code, the class password and its countdown, so it can go on the projector. QR drawn at the displayed size, so it stays sharp.
- **A2 Locked class code:** arriving from the QR shows the code as a fixed label (no editable field) and loads the name list automatically. Typing the address without a code still gives a normal field.
- **A3 Universal class password:** one shared password, reusable by any number of students, refreshes every 30 s; the previous password is accepted for 10 s after an automatic refresh. **New password now** invalidates at once. Teacher admission still required. (`server/join-password.mjs`)
- **A4 Admit all:** one tap admits every waiting student; anyone waiting on two devices is named and left for an individual choice.
- **A5 Changing classes:** saved math sets (save / use for this class / delete; included in export and in Clear all), **Sign everyone out** (keeps students, history, math and the class code), **Replace roster** (U-09: count shown, export offered, two confirmations; math kept).
- `?` help (U-02) beside the class password, saved math sets, Admit all and the class-change buttons. Open help boxes now stay open while the desk refreshes.
