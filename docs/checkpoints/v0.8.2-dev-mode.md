# Math Arcade v0.8.2 — DEV playtest from the teacher desk (implementation checkpoint)

**Status:** Implementation checkpoint. Not merged or deployed. Spec: [v0.8.0](../change-specs/v0.8.0.md) §5a (E1); handbook U-13 as amended 2026-10-15 (handbook `053e72c`).

## What changed

- Teacher desk shows a **DEV PLAYTEST** card (always, even with no class) listing the nine action games: False Haven, Journey, Blackline, Kingsgate, Blackout, Coastal Escape, Vault 7, Nightfall 1, Ironbreak.
- Each opens MathQuest's shared DEV setup panel (`/coastal/engine/dev-playtest.js`): banner "DEV PLAYTEST · [Game] v[version] · no questions, no records", power-ups (all ticked by default), starting point (Vault 7 route; Journey hero), Journey's free upgrade, Threat for False Haven / Nightfall 1, Start, Back to the desk.
- The game runs in the same Arcade host and game code students use. Leaving or finishing returns to the setup panel (U-13 "Restart returns to the setup panel").
- Server: `/api/dev/*`, teacher sign-in required. Each teacher gets one in-memory sandbox; nothing is written to the workspace, so no student, class, session, export or deletion records. Kingsgate's between-wave question rounds are skipped with full credit.
- Chrono Circuit, Olivia and Math Civ are excluded: they keep their own native math and their own repositories' DEV playtest files (U-13 standalone route).

## Not implemented (recorded under U-06)

- **Starting checkpoint inside a level:** the Arcade's round creation for these games exposes no mid-level checkpoint option; the panel says "Starts at the beginning" except Vault 7 (route) and Journey (hero). Adding mid-level starts needs changes in the canonical games (MathQuest).
