## Delivered behavior

- Vault 7, Nightfall 1 & 2, Journey (single player), Blackline, Coastal Escape and Ironbreak run on the student's device. Server replies no longer overwrite a running round. The device reports snapshots at least every 0.5 s and with every pause/resume/command. The server stores them within a generic envelope (size, finite values, current running round, fresh sequence, outcome cannot be cleared, mode cannot change) and enforces each game's time limit from server-measured active time plus 5 s grace. Accessible/guided modes remain server-stepped.
- Long-disconnect stop changed from 1.5 s to 10 s.
- Olivia's Magic Bracelet Quest and Chrono Circuit gates use the standard Arcade gate layout, four-column keypad and fraction display.
- Vendored games unchanged (mathquest `cd35fd9`, equal to MathQuest main at implementation time).
