# Math Arcade v0.5.0 — release notes

**A WILLIAM MCADA PRODUCT** · 13 October 2026

Release of verified candidate 0.5.0-rc.3 (`52cdd4a` application code; verification in `docs/checkpoints/v0.5.0-verification.md`; spec `docs/change-specs/v0.5.0.md`). This release step only changes version numbers and documentation.

## What changed

- All Arcade mathematics comes from Math Engine 0.34.0-rc.3 (MATH-ENGINE `10127fc`), the same build MathQuest 0.10.0 uses: 312 K–7 skills, 1,441 course items Intermediate 4 → Algebra 2 with lesson names, 10 extras.
- Teacher math settings: Browse by grade, course or extras; search across every level; preview renders engine items. Course items run in Mixed Review — Targeted.
- Gates (arcade and adventure) show engine-rendered questions and the keys each answer needs.
- Existing K–7 skill IDs are unchanged, so class settings, overrides and progress continue.

## Deployment order

1. Merge MATH-ENGINE #4, then MathQuest #8 (MathQuest's own deployment follows its release notes).
2. Merge Math Arcade #2 into `main`. **Verify Math Arcade candidate** runs automatically on `main`.
3. When it succeeds, open Actions → **Deploy verified Cloudflare candidate** → Run workflow, and paste that verification run's ID.
4. Open the Arcade's `/?role=teacher` page and confirm it shows v0.5.0.

The hourly sync will then pull MathQuest 0.10.0's game snapshots and the engine from their `main` branches; each sync is verified before it is promoted and deployed separately.
