# Math Arcade v0.6.0 — release notes

**A WILLIAM MCADA PRODUCT** · 13 October 2026

- **New game: Kingsgate.** Orc warbands attack a walled city in twelve waves. Students build and upgrade towers by tapping the field. There is no math gate before Kingsgate: before each new wave the student answers a short question round, and every correct first answer earns 30 gold. Questions use the student's own assignment and are checked by the Math Engine on the server.
- Teachers enable Kingsgate like any other game. Question rounds count toward first-attempt accuracy in reports.
- Version 0.6.0. See `docs/change-specs/v0.6.0-kingsgate.md`.

Deploy after MathQuest v0.11.0 is merged, so the pinned game source is on mathquest `main`.
