## Owner request

"I need to be able to search by lesson, standard, topic/key word." Browse showed one course but search ignored it; "lesson 9" returned unrelated results; the course choice should be ticks; the grade range should apply only to K–7 skills.

## Findings at the baseline

- Typing a search ignored Browse and the grade range and searched all 1,763 skills.
- Every search word was a substring test against internal ID + name + standard + course + lesson. "9" matched any 9 in an internal ID, so "lesson 9" returned 401 skills; only 7 are in a Lesson 9.
- The Engine sent blank standards for every course item (fixed in Engine 0.35.0).
- The grade range only filtered the K–7 browse list, though it appeared for every course.

## Design

1. **Course ticks replace Browse.** One checkbox per course (K–7 skills, Intermediate 4, Course 1, Introduction to PreAlgebra (8/7), Algebra 1/2, Algebra 1, Algebra 2, Math Engine extras) with counts. Ticked courses set the scope of both browsing and searching. On opening, the courses that hold already-selected skills are ticked; otherwise K–7 skills. Selecting a skill ticks its course.
2. **Search understands the query.**
   - Lesson: "lesson 9", "L9" or a bare "9" matches lesson number 9 exactly; "investigation 2" and "appendix B" likewise.
   - Objective: "9.6" matches a standard ending in .9.6 or an 8/7 objective ID ending -9.6.
   - Standard: a token with letters and dots ("PS.MAT.G5.NF", "4.NF") matches standards or aliases containing it.
   - Keyword: every other word must start a word in the skill name or topic (not internal IDs, not the lesson title).
   - Parts combine with AND ("lesson 9 multiply").
3. **Scope controls.** "Search every course and grade" searches everywhere. When a search has matches outside the ticked courses or grade range, the count is shown with a "Show them" button.
4. **Grade range** ("First/Last grade (K–7 skills)") is shown only when K–7 skills is ticked or the mode is General Review / Fixed Progression, which draw from K–7 skills by grade. It limits K–7 skills in browsing and searching. Saved settings keep their range either way.
5. **Results** are grouped under headings (course · lesson, or K–7 · grade) in teaching order, showing the 8/7 standard code beside each item; at most 300 shown with a count.
6. **Help (U-02):** "How search works (?)" explains each query form and the limits, including that only 8/7 and K–7 skills have standards recorded.

## Not changed

Gate behavior, modes, saved configuration format, student pages, games, and question generation. Server change is limited to sending `alias` and `topic` with catalog rows.
