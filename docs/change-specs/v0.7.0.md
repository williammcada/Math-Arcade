# Math Arcade v0.7.0 — every game current, Blackout Protocol, card art, automatic deployment

**Status:** Owner-requested 14 October 2026 (Asia/Shanghai): "Math Arcade needs to be forced to sync with all games – Kingsgate & Blackout need to go in. Also cartridge art needs to display more prominently … everything after Vault 7 seems to have no visible cartridge art … Sekigahara doesn't have cart art but an image can be extracted and added." Owner then asked to "analyze and fix" game changes that had not synced. Branch `implement/arcade-v0.7.0`.
**Baseline:** Math-Arcade `main` `de1b39f` (v0.5.0 platform, Render front door). Live Worker before this release: Arcade `e0f9c8e`, carrying mathquest `e79fdb8`.
**Handbook consulted:** `mcada-project-handbook` `75baa80` — UNIVERSAL-RULES (U-01, U-06, U-07, U-10, U-12, U-13, U-14, U-15), CONDITIONAL-STANDARDS (S-04).

## Findings (why games looked unsynced)

1. **Arcade never redeployed after its hourly sync.** The sync commits with the workflow token, which does not start the Verify workflow, and the deploy workflow only ran for one opted-in commit message or a manual dispatch. The live Worker therefore still ran mathquest `e79fdb8` — before the Coastal/Ironbreak/Blackline difficulty revision, the Math Engine and Kingsgate.
2. **Kingsgate's Arcade entry (PR #5, v0.6.0) was verified but never merged.**
3. **Blackout Protocol and Nightfall Art Direction never reached MathQuest `main`** (fixed in MathQuest v0.12.0).

## Changes

- **Merge PR #5** (Kingsgate entry, v0.6.0) unchanged.
- **Sync** every mathquest game to the MathQuest v0.12.0 verified candidate `86e6b3f` (difficulty revision, Nightfall art, Kingsgate, Blackout); new `blackout` sync group (`public/games/blackout/`, `public/assets/blackout/`). Chrono, Olivia, Math Civ and Math Engine are already at their `main`.
- **Blackout Protocol entry** (`blackout`, round policy): math gate → equipment choice (Spare Fuse, Grid Scanner, Surge Stabilizer; any combination) → five-minute device-run puzzle. Canvas taps map through the letterboxed board as in MathQuest; Energize and Scanner presses are latched so a short tap counts once. No guided route (MathQuest's guided panel is classroom-only). The puzzle object is rebuilt from saved snapshots on the device and server (`revive`), so reloads continue the same board. Timeout `timed_out` at 300 s.
- **Card art:** every card shows full 16:9 art with no title box over it; title, type and description sit below. New small card images for all 12 games in `public/covers/` (see `docs/COVERS.md`), including Sekigahara's title painting extracted from the Math Civ build. Old per-game background rules removed (they also loaded full-size covers). Kingsgate's card says "Questions between waves" / "Defend the gate".
- **Automatic deployment:** the deploy workflow now deploys every `main` commit whose full Verify run passes (push or dispatch); pull-request runs never deploy. The canonical sync runs after school only (17:17–06:17 Asia/Shanghai) and starts Verify for each promoted commit, so synced games go live the same evening.
- **Version (U-01):** 0.7.0 (package, server, page title and header, build provenance).

## Must retain

Every existing game, gate, campaign, admission, pause/resume, saved work and reports; Kingsgate behaviour from v0.6.0; Render front door and relay unchanged.

## Order of release

MathQuest v0.12.0 must be merged first: until then the after-school sync would try to re-pin Arcade to an older mathquest `main` without Blackout. The sync refuses to drop a pinned file, so it fails safely instead of breaking the Arcade.
