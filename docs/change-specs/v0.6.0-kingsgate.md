# Math Arcade v0.6.0 — Kingsgate entry

**Status:** Implemented under the approved Kingsgate v0.1 specification (`williammcada/kingsgate` `docs/change-specs/kingsgate-v0.1.md`, revision 2, approved by William McAda on 2026-10-13). This file records how it lands in Math Arcade.

**Baseline:** Math-Arcade `main` `bc477d1` (v0.5.0, Math Engine 0.34.0-rc.3 `10127fc`). Game source: mathquest `implement/kingsgate-v0.1` `e5962a4` (MathQuest v0.11.0 verified release, pull request #10). Re-pin to the merged mathquest `main` commit once it merges; the hourly sync then keeps it current.

## Owner decisions
- Kingsgate is a Math Arcade entry and a MathQuest cartridge, not a standalone game.
- **No round gate.** Questions come between waves instead; they replace Arcade's standard math gate before each round.
- After waves 1–11 the student answers a question round; +30 gold per correct first answer.

## Exception recorded
Arcade v0.4.0 says each new game has one math gate before a round, then uninterrupted action. For Kingsgate the owner replaced that gate with between-wave question rounds.

## Implementation
- Sync group `kingsgate` copies `public/games/kingsgate/` and `public/assets/kingsgate/` from mathquest (pinned in `vendor/manifest.json`, hydrated at build like Blackline).
- `begin('kingsgate')` grants the round directly. `launch` creates an Arcade-rules defense: 120 starting gold, all four towers, no equipment.
- `/api/kingsgate` `break`: accepts the device snapshot, confirms a question round is due, opens it with the student's assigned skills and pauses the round clock. Question count is the teacher's gate count, limited to 1–5.
- `/api/kingsgate` `answer`: one attempt per question, checked by the Math Engine on the server; correct answers are credited; a wrong answer returns the correct answer. First attempts appear in teacher reports.
- Snapshots are rejected if question gold exceeds the server-credited answers, a wave starts before its question round, or round settings change.
- Guided defense through `/api/extra`, recorded as `assisted_completed`.
- Client `public/kingsgate-game.js`: tap-to-build field, question panel over the battlefield.
- Platform version 0.6.0.
