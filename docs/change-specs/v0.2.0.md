## Admission

QR contains a stable session locator, never the password. Teacher sees a random four-letter uppercase password and countdown. Each password expires after 45 seconds and can be redeemed by one device only. Redemption and consumption occur in the same database transaction. A used password stays used until expiry or teacher presses New password. Existing admitted students remain connected. Teacher approves roster identity/replacement; approval invalidates previous student credentials. New passwords do not extend old validity. Reject missing, expired or consumed passwords; throttle join attempts. Normalize lowercase input. Preserve passwords/expiry across process restart; do not repeat a code during the session. Classroom pause/end prevent new joins. No join secrets in student APIs or QR URLs.
