# Math Arcade v0.4.1 — smooth action play and consistent campaign gates

Approved by William McAda on 12 October 2026 (Asia/Shanghai) after owner playtest feedback.

Baseline: Math-Arcade main `361fe633e07b6b6ab9bad51c870c6e645877f241`, runtime v0.4.0-rc.1. Upstream game snapshots: mathquest `cd35fd912fbde2007f8fade6b93b1c2a1421275c` (unchanged; equal to MathQuest's current main). Handbook `fd43308`: AI-START-HERE, UNIVERSAL-RULES (U-01, U-06, U-07, U-10), CONDITIONAL-STANDARDS S-03/S-04 consulted. No handbook edits.

## Reported problems

- Nightfall 1: Last Bus Out, Nightfall 2: False Haven, Journey to the West — Single Player, Blackline, Coastal Escape and Ironbreak: the player avatar bounces erratically; the games are unplayable. All play correctly in MathQuest Dev mode.
- Olivia's Magic Bracelet Quest (OMBQ): the gate number pad formatting is odd and inconsistent with the other games.
- Updates must stay synchronized between MathQuest and Math Arcade.

## Diagnosis

The vendored game code is identical to MathQuest; synchronization is not the cause. The Arcade host differs:

1. Each action client simulates locally at 60 Hz, sends its keys every 140 ms, and then replaces its entire local state with the server's snapshot from the reply (`apply()` → `this.sim = structuredClone(round.snapshot)`). The server simulates separately from wall-clock time with the previously received keys, so its state lags by the network round trip. The avatar snaps backward several times per second. Local tests ran at near-zero latency and could not show it. Vault 7 uses the same pattern and is included in the fix.
2. The server stops a round when more than 1.5 s passes between syncs (`advance()`), producing freezes on slow networks.
3. Olivia and Chrono Circuit gates use a separate hand-built `classroom-gate` panel (system font, five-column keys) instead of the standard Arcade gate layout.

## Accepted behavior (owner decisions)

**Game state — MathQuest model.** For Vault 7, Nightfall 1, Nightfall 2, Journey (single player), Blackline, Coastal Escape and Ironbreak:

- The iPad runs the game. Server replies never overwrite a locally running round.
- The client sends a snapshot of its own state at least once per second, with every pause/resume action and when an outcome is reached. Heartbeats continue at the existing interval for teacher pause/end responsiveness.
- The server stores the client snapshot only for the current round, with a fresh sequence number, while the round is running. It applies a generic envelope: size limit, finite values only, an outcome cannot be cleared, and server-measured active time enforces each game's existing time limit (Nightfall 1: 7,200 s review envelope; Vault 7 and Journey: 180 s; Nightfall 2, Blackline, Coastal Escape, Ironbreak: 300 s) with a 5 s grace period. The server no longer simulates rounds.
- The server still owns math gates, round admission, teacher availability, pause and end, saves, rewards and reports. Reload or restart resumes the last accepted snapshot, paused, with no renewed lives, time or grants.
- Replace the 1.5 s auto-stop with a long-disconnect rule: more than 10 s without contact stops the round and neutralizes input (unchanged U-10 requirement). The client's existing connection-loss pause remains.
- Guided/accessible-mode commands keep their existing server-side handling.

**Gate formatting.** The OMBQ and Chrono Circuit campaign gate uses the same layout, typography, four-column keypad, answer field, progress and "Check answer" button as the standard Arcade gate. Gate rules, draft persistence, credit and the campaign's own progression are unchanged.

**Synchronization.** Hourly upstream synchronization is unchanged. The Arcade host now runs games the same way MathQuest does, so upstream game changes behave the same in both.

## Known limitation, accepted

MathQuest additionally runs detailed per-game anti-tampering validators (e.g. ammunition, enemies, objectives). Arcade v0.4.1 uses the generic envelope above. Arcade round outcomes end a round and label the roster; they do not award extra rounds or grants, so the remaining risk is limited. Porting per-game validators is a possible later change.

## Must retain
