# Math Arcade v0.11.1 — start game art during the math gate

**Status:** Owner-approved 16 October 2026 as Phase 4 of the [game-loading plan](game-loading-2026-10-16.md). Implemented on `implement/v0.11.1-early-art` from `main` `b312700` (0.11.0-rc.1).

## Change

- `public/art-preload.js`: one shared art cache per page. Each game host registers its loader (Nightfall, Coastal Escape, Kingsgate, False Haven, Blackline, Journey, Blackout); the first call starts the download and later calls reuse it. A failed load is forgotten, so the host's existing error and retry behaviour is unchanged.
- `public/app.js`: when the student state shows a gate or a granted round for a chosen game, that game's art starts downloading. Only the chosen game loads.
- Game hosts take their art from the cache instead of calling `loadArt()` at Start.
- Synced MathQuest 0.14.2 (`6d185cb`): Journey and Nightfall art is now WebP. Pins for other upstream repositories are unchanged. The manifest drops the 39 PNG and provenance files MathQuest moved out of `public/`; without that, the scheduled sync stops with "required adapter dependency removed".

## Not changed

Gate rules, rounds, scoring, DEV mode, campaign games (Chrono, Olivia, Math Civ open in their own frame without an Arcade gate), Vault 7 and Ironbreak (no adapter art to preload). Caching headers: unchanged in this version; measured on the live site after deploy (plan Phase 0).

## Version

0.11.1-rc.1 (package, page title and header, build provenance, server `VERSION`).
