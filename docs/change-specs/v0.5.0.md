# Math Arcade v0.5.0 — Math Engine K–Algebra 2

**Status:** Approved design (MATH-ENGINE `docs/change-specs/host-integration-v0.1.md`, D1–D4 approved by William McAda 2026-10-12; D5 working design). Review branch `review/arcade-0.5.0-engine`; not released or deployed.
**Baseline:** `main` at `099f19c` (Arcade 0.4.1-rc.1).
**Engine:** Math Engine 0.34.0-rc.2, MATH-ENGINE `414dc38`, `dist/math-engine-practice.js` (Git blob `df989f0`, SHA-256 `a1379220…019d`). Same build as MathQuest 0.10.0-rc.2 (`aeef610`), so the two stay in sync.
**Handbook consulted:** `mcada-project-handbook` `fd43308` (U-01, U-04, U-06, U-07, U-09, U-10; S-03-M; S-04).

## Changes

- **Math source:** Arcade vendors the engine's practice bundle instead of the K–7-only `megaman-v0.7` baseline. Questions, answer checks and gate control (`Practice`, `freshMath`, `configError`) come from it. The bundle is server-side only; browsers receive engine-rendered `html`, the answer keys the item needs, and its input mode. `/math-format.js` is no longer served.
- **Content:** existing K–7 skills keep their IDs, so saved class settings, overrides, progression history and fact decks continue. Teachers can also choose course items from Intermediate 4 → Algebra 2 and the engine extras. These are used in Mixed Review — Targeted (the picker switches mode when one is chosen); General Review and Fixed Progression stay K–7.
- **Teacher picker:** new Browse control (K–7 by grade range, each course, extras); search covers every level; labels show grade or course. Preview renders engine items.
- **Catalog delivery:** the 1,763-row catalog is fetched once from `/api/catalog`; the 1.5-second teacher poll carries only its hash.
- **Gates:** both the arcade gate and the adventure (Chrono/Olivia) gate render engine `html`; the keypad shows the keys the item needs (e.g. `;` for systems); choice items show their options as keys.
- **Sync:** `scripts/sync-upstream.mjs` now takes `dist/` from MATH-ENGINE. Until the engine's 0.34 work is merged to MATH-ENGINE `main`, the hourly sync on Arcade `main` must not pull from `main` — merge the engine first, then this branch.
- **Version (U-01):** 0.5.0-rc.1 (package, server, page title/header, build provenance).

## Preserved

Game list, gate counts and terminal-condition rules, single-use join passwords, admission, pause/resume/end, campaigns and their gate keys, Math Civ built-in math (no gates), Journey exclusion, saved-work deletion (U-09), held-input handling (U-10).

## Out of scope

Mega Man, Math Civ, Olivia/CHRONO standalone builds, MathQuest changes, deployment.

## Known limitation

Course items carry no lesson labels in the engine (Studio holds them), and some course titles repeat (e.g. "Find a missing number"). Teachers can preview to tell them apart. Follow-up: move lesson labels into the engine catalog.
