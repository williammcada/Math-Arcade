## Problem

Students could meet questions that need several answers at once, such as "Rename 1/3 and 1/2 using their least common denominator. Enter first numerator; second numerator; common denominator" (answer `2; 3; 6`), or a system of equations answered "x; y". Engine 0.37.0 tags these and removes them from the game catalog: 1,441 course items become 1,158.

The Engine refuses any selection that names an id it no longer offers ("Choose valid skills."). Without a host change, a class default, an individual setting, a saved math set or an open gate that still named a removed question would stop students starting games and stop the teacher saving or applying sets.

## Design

### Engine bundle

`vendor/math/math-engine-practice.js` and its provenance come byte-for-byte from MATH-ENGINE `574d4c0`. `vendor/math/answer-pad.js` is unchanged (same blob). Only the math group of `vendor/manifest.json` changes; other games are not re-synced.

### Start-up cleanup (`server/engine-migration.mjs`)

Runs inside the model constructor on every start, on the Node host and the Cloudflare Worker alike. It is idempotent.

- **Class defaults:** removed ids are dropped. If nothing valid is left, the default falls back to default practice settings, keeping the questions-per-gate and Kingsgate-per-wave counts.
- **Individual settings:** removed ids are dropped. If nothing valid is left, the student returns to the class default.
- **Saved math sets:** removed ids are dropped. Sets are never deleted. A set left with no skills says so when applied.
- **Students' practice state:** progression position and return path skip removed skills.
- **Open gates** (arcade gates, Kingsgate breaks and saved Chrono/Olivia adventure gates): the gate's selection and draw bag are cleaned. If the current question came from a removed skill, the next question is drawn and the item id changes, so an old answer gets "Question changed." Progress already made in the gate is kept.
- **Notice:** when anything was removed, the workspace records the count, the reason ("multi-part") and the places affected.

### Teacher notice

The teacher desk shows a "Math update" card above the class banner. It says how many skills were removed and from where, and that Studio packets still include them. **Got it** dismisses it for good (`POST /api/math-notice/dismiss`).

## Not changed

Games, answer pad, gate counts, rewards, reporting, Math Civ (built-in math), and every other vendored game snapshot.
