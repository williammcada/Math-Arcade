## Problem

A student in Math Arcade met a question that needed a remainder "R" and had no way to enter it. The Arcade drew three different answer pads:

- the main gate (`public/app.js`)
- the adventure gate used by Chrono Circuit and Olivia's Magic Bracelet Quest (`public/campaign-runtime.js`)
- the Kingsgate question round (`public/kingsgate-game.js`)

Each drew whatever keys the Engine listed for that question. Before Engine 0.36.0 that list depended on the answer, so keys could be missing or could hint at the answer.

The older Chrono and Olivia pads under `vendor/` are not live: the build replaces their gates with the adventure gate.

## Design

1. **Engine files.** Vendor MATH-ENGINE `9452ab4`, byte for byte, into `vendor/math/`:
   - `dist/math-engine-practice.js` and its provenance file. Every keypad question now carries the universal key list, and pad-typed answers are accepted.
   - `src/answer-pad.js`, the pad itself.

   The manifest records the commit. `scripts/sync-upstream.mjs` adds `src/answer-pad.js` to the math group, so future syncs keep it current.
2. **Browser module.** The build converts `vendor/math/answer-pad.js` into a browser module, `/answer-pad.js`, using esbuild. The browser code is the Engine's, unchanged. The Node host and the Worker assets both serve it.
3. **One Arcade answer-entry helper,** `public/answer-entry.js`, used by all three screens. It chooses the entry method from the question:
   - **Keypad questions:** the Engine pad (two tabs, 123 first). The answer box is read-only with `inputmode="none"`, so the iPad keyboard does not cover the pad. A physical keyboard still types any pad character, and Enter submits.
   - **Choice questions:** answer buttons, as now.
   - **Text questions** (words, letters A–E, Roman numerals): a normal text box with the device keyboard, as now.

   Each new question mounts a fresh pad, so the pad opens on 123. The previous pad is removed, along with its keyboard listener.
4. **Screens.** Each screen keeps its own layout and wording. Only the entry area changes. Drafts and the answer kept after a wrong try (main gate, adventure gate) continue to work through the helper.
5. **Version** 0.10.0-rc.1 in `package.json`, `server/core-model.mjs`, the build provenance and the Worker title test.

## Not changed

Game code, gate rules, question counts, Kingsgate gold and the per-wave setting. Teacher screens, the U-17 directional pads (owned by MathQuest), sound, and hosting are also unchanged.
