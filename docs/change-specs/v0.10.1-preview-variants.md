# Math Arcade v0.10.1 — "Next variant" in the teacher math preview

**Status:** Requested by William McAda on 2026-10-16 (Asia/Shanghai): "When I preview content in Math Quest/Math Arcade delivered via Math Engine - I want a 'next variant' button so I can screen the questions quickly." Implementation checkpoint (0.10.1-rc.1); not a verified release or deployed.
**Baseline:** `main` `316864a` (after PR #17 test fix; originally branched from `adab5cc`) (0.10.0-rc.1, universal answer pad — itself not yet verified). Stacked on it; v0.10.0's scope is unchanged.
**Math Engine:** unchanged, 0.36.0-rc.1 (`9452ab4`).
**Handbook:** `9d9c80f` (v0.1.12). U-01, U-06 (variant 0 is today's sample), U-07, U-14 (the Engine owns seeded generation; the Arcade only picks the index).

## Problem

The teacher's math-settings **Preview** generated every skill with seed `preview:<id>` at index 0, so each skill always showed the same single question.

## Change

1. **Server:** `POST /api/preview` accepts an optional `variant` (non-negative integer; default 0; clamped to 9999). `Model.preview` asks the Engine for the same seed at `index = variant` and returns `variant` with each item.
2. **Teacher screen:** the preview card shows "VARIANT N" and a **Next variant** button before **Next skill**. Next variant fetches only the skill on screen at the next index; Next skill and Close behave as before.
3. **Unchanged:** variant 0 equals the previous sample. Preview remains teacher-only and changes no settings or student evidence.
